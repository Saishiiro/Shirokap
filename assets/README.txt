Customize Shirokap
==================
Simply replace these files (keep the same names), then run build.bat again:

  logo.png  -> tray icon and gallery window icon
               (square PNG, 64x64 minimum, transparent background recommended)
  logo.ico  -> icon of shirokap.exe in Explorer
               (a real .ico, ideally with 16/32/48/256 sizes)
  beep.wav  -> sound played after a capture (the "Beep" setting)
               (WAV format, short: under one second)

The files are embedded in the exe at build time:
the final shirokap.exe stays a single file.


Personnaliser Shirokap
======================
Remplace simplement ces fichiers (garde les memes noms), puis relance build.bat :

  logo.png  -> icone du tray et de la fenetre de la galerie
               (PNG carre, 64x64 minimum, fond transparent recommande)
  logo.ico  -> icone du fichier shirokap.exe dans l'Explorateur
               (un vrai .ico, idealement avec les tailles 16/32/48/256)
  beep.wav  -> son joue apres une capture (reglage "Bip sonore")
               (format WAV, court : moins d'une seconde)

Les fichiers sont integres dans l'exe a la compilation :
le shirokap.exe final reste un fichier unique.
